# 🌸 KIMETSU NO YAIBA: WISTERIA DEFENSE
### Permainan Tower Defense Bertema Anime Demon Slayer (Gaya Plants vs Zombies) dengan Sistem Skor Pencapaian

Selamat datang di **Kimetsu no Yaiba: Wisteria Defense**, sebuah permainan strategi *Tower Defense* jalur mendatar (5 jalur) yang terinspirasi dari mekanisme klasik *Plants vs Zombies*, namun diadaptasi dengan karakter, jurus pernapasan, dan atmosfer anime **Kimetsu no Yaiba (Demon Slayer)**!

---

## 🌟 Fitur Utama Permainan

1. **Mekanisme 5 Jalur Pertahanan (PvZ Grid Mechanics)**:
   - 5 baris pertahanan melintasi Hutan Gunung Fujikasane yang suci.
   - Iblis bergerak maju dari sisi kanan menuju ke sisi kiri arena.
   - Di ujung kiri setiap jalur, terdapat **Gerbang Torii Suci** dengan pedang Nichirin berkilau yang berfungsi sebagai garis pertahanan terakhir (seperti *Lawn Mower* pada PvZ). Jika iblis menyentuh gerbang, pedang Nichirin akan melesat menyapu seluruh iblis di jalur tersebut!

2. **Mata Uang Kelopak Wisteria (🌸 Wisteria Petals)**:
   - Iblis sangat takut dan benci terhadap bunga Wisteria.
   - Tanam **Dupa Wisteria (Kakushi)** untuk memproduksi 25 kelopak secara berkala (seperti *Sunflower*).
   - Kelopak Wisteria juga jatuh melayang secara alami dari pohon wisteria malam. **Klik kelopak** yang melayang untuk mengumpulkannya!

3. **10 Unit Pembasmi Iblis (Kisatsutai)**:
   - **Tungku Dupa Wisteria / Kakushi (50🌸)**: Penghasil sumber daya wisteria berkala.
   - **Tanjiro Kamado (100🌸)**: Menembakkan tebasan ombak air (*Mizu no Kokyu* - Mizunoguruma).
   - **Zenitsu Agatsuma (175🌸)**: Kilat kilat (*Hekireki Issen*) yang menembus hingga 3 musuh sekaligus dengan efek stun.
   - **Inosuke Hashibira (150🌸)**: Petarung jarak dekat ganas dengan pedang bergerigi ganda dan efek dorongan (*knockback*).
   - **Nezuko Kamado (125🌸)**: Darah Iblis Meledak (*Bakketsu*), menyemburkan api iblis pink dengan luka bakar area dan efek perlambatan (*slow*).
   - **Shinobu Kocho (200🌸)**: Menusukkan jarum racun wisteria murni (*Mushi no Kokyu*), membakar darah iblis secara bertahap dan **menembus zirah baja**!
   - **Kyojuro Rengoku (250🌸)**: Meluncurkan tebasan harimau api (*Flame Tiger*) berdaya hancur tinggi yang membakar semua iblis di sepanjang jalur!
   - **Giyu Tomioka (225🌸)**: Memancarkan jurus ketenangan air ke-11 (*Nagi - Dead Calm*), memperlambat dan meredam musuh di 3 jalur sekitarnya.
   - **Batu Latihan Urokodaki (50🌸)**: Dinding batu pertahanan super kokoh berikat shimenawa (HP 3.200) untuk menahan laju iblis (seperti *Wall-nut*).
   - **Bom Suara Uzui Tengen (150🌸)**: Meledak setelah 1,2 detik dengan kembang api flamboyan dahsyat memusnahkan iblis di area 3x3 petak!

4. **8 Ragam Iblis (Oni) & Musuh Bos**:
   - **Iblis Biasa (Lesser Oni)**: Iblis standar berdarah dingin.
   - **Iblis Lincah (Fast Oni)**: Berlari kencang menerjang pembasmi.
   - **Iblis Berzirah Baja (Armored Oni)**: Bertubuh besar dengan pelindung bahu berduri, tahan tebasan fisik (sangat rentan terhadap racun Shinobu Kocho!).
   - **Susamaru (Temari Demon)**: Melemparkan bola temari berduri yang memantul dari kejauhan.
   - **Yahaba (Arrow Demon)**: Memanipulasi vektor panah merah mematikan.
   - **Boss Rui (Lower Moon 5)**: Memancarkan benang laba-laba merah yang menjerat pembasmi.
   - **Boss Akaza (Upper Moon 3)**: Melancarkan gelombang tinju penghancur *Hakai Satsu*.
   - **Final Boss Muzan Kibutsuji (Demon King)**: Memiliki HP masif, regenerasi darah otomatis, dan cambuk tentakel hitam berduri!

5. **Ultimate: Tarian Dewa Api (Hinokami Kagura: Enbu)**:
   - Setiap iblis yang dikalahkan mengisi meteran energi *Hinokami*.
   - Ketika mencapai 100%, tombol matahari terbit membara! Tekan untuk memanggil naga api membakar bersih seluruh iblis di semua 5 jalur!

6. **🏆 Sistem Skor & 15 Pencapaian (Achievement Score System)**:
   - **Skor Dinamis & Kombo**: Membasmi iblis berturut-turut menghasilkan pengali *Combo Multiplier* hingga 3.0x lipat!
   - **Rekor Skor Tertinggi**: Tersimpan otomatis di *Local Storage*.
   - **15 Pencapaian Khusus**:
     1. 🌸 **Lulus Seleksi Akhir** (+100 Poin)
     2. 🌊 **Tebasan Pernapasan Air** (+150 Poin)
     3. ⚡ **Kilat Kecepatan Dewa** (+150 Poin)
     4. 🐗 **Serbuan Raja Gunung** (+150 Poin)
     5. 🩸 **Ledakan Darah Iblis** (+150 Poin)
     6. 🦋 **Tarian Capung Racun** (+200 Poin)
     7. 🔥 **Bakar Semangat Jiwamu!** (+200 Poin)
     8. 🌊 **Ketenangan Air (Nagi)** (+200 Poin)
     9. 💥 **Pesta Suara Flamboyan** (+200 Poin)
     10. ☀️ **Tarian Dewa Api** (+250 Poin)
     11. 🌸 **Penguasa Lembah Wisteria** (+250 Poin)
     12. ⛩️ **Benteng Tak Tertembus** (+300 Poin)
     13. 🕷️ **Penenun Jaring Gugur** (+350 Poin)
     14. ❄️ **Pukulan Kehancuran Patah** (+400 Poin)
     15. 👑 **Akhir Sang Raja Iblis** (+500 Poin)
   - Notifikasi *Toast Animation* muncul secara *real-time* saat pencapaian terbuka!
   - Papan dialog khusus pencapaian dengan progress bar dan rekap poin total prestasi.

7. **Sintesis Audio Kustom (Web Audio API)**:
   - 100% mandiri tanpa ketergantungan file MP3 eksternal yang lambat atau rusak.
   - Melodi Koto/Shamisen Jepang tradisional & dentuman drum Taiko berirama dinamis.
   - Efek suara tebasan pedang (*shing!*), petir Zenitsu, deburan air Tanjiro, kobaran api Rengoku, lonceng wisteria, dan seruan kemenangan!

8. **6 Tingkat Wilayah + Mode Bertahan Hidup (Endless Mode)**:
   - Level 1: Seleksi Akhir Gunung Fujikasane
   - Level 2: Penyerangan Kuil Malam
   - Level 3: Rumah Drum Kyogai
   - Level 4: Hutan Gunung Natagumo (Boss Rui)
   - Level 5: Kereta Tak Berujung - Mugen Train (Boss Akaza)
   - Level 6: Infinity Castle (Boss Muzan)
   - **Mode Bertahan Hidup (Endless)**: Ujian Tanpa Batas dengan gelombang iblis berlipat ganda!

## 🚀 Cara Menjalankan Permainan

Kamu bisa langsung memainkan game ini dengan cara:

### Cara 1: Buka Langsung di Browser (Paling Mudah)
Cukup buka file `index.html` dengan klik dua kali (atau drag ke Google Chrome / Microsoft Edge).

### Cara 2: Menjalankan Menggunakan Server Python Lokal
Buka Terminal / PowerShell di folder ini lalu jalankan:
```bash
python -m http.server 8000
```
Lalu buka peramban dan kunjungi:
```
http://localhost:8000
```
